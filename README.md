# Korvet manager

Полноценный прототип приватного E2E-чата: текст, фото и большая локальная коллекция русских мем-стикеров.

## Что уже есть

- React/Vite клиент
- Node.js + Socket.IO сервер
- Комнаты по секретному ключу
- E2E-шифрование в браузере через Web Crypto API
- Сервер хранит только ciphertext
- Фото шифруется внутри payload
- Стикеры локальные, без внешних CDN
- Stealth mode
- Panic wipe
- Safety number для сверки ключа
- Автоудаление отключено

## Локальный запуск

```bash
npm install
npm run install:all
npm run dev
```

Открой клиент Vite, обычно:

```text
http://localhost:5173
```

Сервер работает на:

```text
http://localhost:3001
```

## Настройка клиента

По умолчанию клиент подключается к:

```text
http://localhost:3001
```

Для продакшена создай `client/.env`:

```env
VITE_SOCKET_URL=https://your-domain.com
```

## Настройка сервера

Можно задать переменные:

```env
PORT=3001
CLIENT_ORIGIN=https://your-domain.com
MAX_MESSAGES_PER_ROOM=500
```

## Продакшен-рекомендации

Для настоящей приватности нужно:

- HTTPS обязательно
- Не использовать CDN для приватного клиента
- Отключить access logs или минимизировать их
- Не хранить IP дольше необходимого
- PostgreSQL/Redis вместо in-memory хранилища
- CSP/SRI/reproducible builds
- Удаление EXIF у фото перед шифрованием
- Signal Protocol / Double Ratchet вместо demo-KDF
- X25519/Ed25519 ключи устройств
- Open-source клиент и независимый аудит
- Tor onion endpoint для приватного режима

## Важно

Этот проект делает так, чтобы сервер не видел содержимое сообщений. Но он не защищает от:
- взломанного устройства;
- вредных расширений браузера;
- скриншотов;
- подмены фронтенда;
- утечки ключа комнаты.


## Версия Telegram-style

В этой версии интерфейс сделан ближе к Telegram:
- левая панель чатов;
- верхняя шапка диалога;
- пузырьки сообщений;
- нижний composer;
- мобильная адаптация;
- панель информации справа.

## Фото-стикеры

В проект не встроены чужие реальные мем-фото, потому что у них могут быть права. Вместо этого добавлен импорт своих фото-стикеров:
1. Нажми кнопку стикеров.
2. Нажми “Добавить реальный фото-стикер”.
3. Выбери мем-картинку с телефона.
4. Отправь её как стикер.

Фото-стикеры хранятся локально в браузере и отправляются в чат только внутри зашифрованного E2E payload.


См. `ANDROID_BUILD.md` для сборки APK.
